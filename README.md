# JUMPMAN
JUMPMAN is the placeholder name for a W.I.P. platformer game I am working on. It was preceded by the older SMMO from 2024.
There is currently nothing as the project is managed externally in Godot. It will be ported to HTML.

## When is it coming out?
No clue. I'm working on a pre-alpha version to test the player physics and mechanics and is planned to release late November.

## What is this "SMMO"?
A modified version of a Scratch game of the same name. It's uploaded along with another old modified game [here](https://ethan-sossa.github.io/archive/SMMO%20v1.5.html).

## What's after the pre-release?
After that I'll add UI and make it all fancy and slowly but surely release the levels of the game. I'm aiming for a good range in difficulties.
